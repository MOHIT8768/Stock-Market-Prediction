# Stock Market Price Prediction

## Overview
A machine learning project that predicts stock prices using Python.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- yFinance

## Features
- Data Collection
- Data Cleaning
- Model Training
- Price Prediction
- Data Visualization

## Installation

pip install -r requirements.txt

## Run

python app.py
